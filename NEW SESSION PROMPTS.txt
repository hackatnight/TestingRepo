### REVERSE-ENGINEERED TOPSTEP / TBUI .BIN & .PA SPEC (SOLVED):
1. **`.PA` RLE + 7-Bit (`2-3-2`) Signed RGB565 Delta Decoder (`window.decodePA`):**
   - `0xC0..0xFF`: Literal `n` opaque RGB565 pixels (`n = c & 0x3F`).
   - `0x80..0xBF`: Run of `n` pixels (`[alpha, lo, hi]` if alpha=1, `[lo, hi]` if alpha=0).
   - `0x00..0x7F`: Single-pixel 7-bit signed RGB565 delta added to previous `(r5, g6, b5)`: `dr = ((c >> 5) & 3) - 2`, `dg = ((c >> 2) & 7) - 4`, `db = (c & 3) - 2`.
2. **Widget Table (`M.widgets`) & Font Lists (`M.fonts`):**
   - Types `0, 4, 5, 6` = Sprite widgets (`hw.a` = sprite ID; `#69` = 360x360 BG; `#70` = 240x240 carousel preview thumbnail).
   - Types `2, 3` = Dynamic Font/Number widgets (`hw.a` = `M.fonts` index; `hw.b` = Horizontal Alignment `0=Left [x + w/2]`, `1=Center [x]`, `2=Right [x - w/2]`).
   - Sub-types (`hw.sub`): `0`=Steps (`FontList[0]`), `2`=Hour (`"09"`, `FontList[2]`), `3`=Minute (`"40"`, `FontList[2]`), `6`=Distance (`"3.25"`, `FontList[3]`, `b=2`), `7`=Kcal (`"103.4"`, `FontList[1]`, `b=2`), `8`=BPM (`"86"`, `FontList[1]`, `b=0`), `11`=Weather Temp (`"72F"`/`"22C"`, `FontList[3]`, `b=0`), `13`=Date (`"06/28"`, `FontList[0]`).
   - Bilingual `[Chinese, English]` Sprite Pairs (`+1` offset for English): `82->83`, `84->85`, `86->87 (KM)` / `88->89 (Mi)`, `90->91 (STEP)`, `92->93 (TEMP)`, `107->108..120 (MON..SUN)`.
